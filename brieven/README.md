# Brieven

Zes brieven met hetzelfde project als onderwerp, maar met per ontvanger een andere
vraag. Verstuur ze niet als rondzendbrief: het feit dát iedereen dezelfde tekst krijgt,
is bij deze ontvangers meestal binnen een week bekend en kost je geloofwaardigheid.

| Brief | Ontvanger | De vraag |
|---|---|---|
| `mooiman-pvv.md` | Tweede Kamerlid Jeremy Mooiman | Input voor de initiatiefwet: wat kun je verplichten en hoe toets je het |
| `ministerie-vro.md` | Ministerie van Volkshuisvesting en Ruimtelijke Ordening | Erken een open referentie-implementatie als publiek ijkpunt |
| `vereniging-eigen-huis.md` | Vereniging Eigen Huis | Bondgenootschap: zij vragen dit al publiekelijk, jij hebt het gebouwd |
| `nen.md` | NEN, beheerder van de NTA 8061 | Conformiteitstoetsing: de invarianten tegen de normtekst leggen |
| `vastgoed-nederland.md` | Vastgoed Nederland | Zij steunen wettelijke regulering al; dit is hoe die eruit kan zien |
| `nvm.md` | NVM | De lastigste: zij hebben een eigen protocol. Aanbod, geen aanval |

## Voor je verstuurt

Drie dingen moeten kloppen, anders val je op de inhoud terug die je juist wilde
vermijden:

1. **Vul de demo-URL in.** In elke brief staat `DEMO_URL` als placeholder. Een brief die
   naar een repo verwijst zonder werkende demo verliest zijn belangrijkste argument:
   dat de lezer het zelf kan narekenen.
2. **Controleer de cijfers.** De meldpunt-aantallen en data komen uit berichtgeving van
   augustus 2026. Noem ze met bron, of laat ze weg.
3. **Zet je eigen naam eronder.** In de brieven staat `[Naam]`.

Wees eerlijk over de status. Dit is een werkende referentie-implementatie met een
uitgeschreven protocol, geen productiesysteem — dat staat ook in elke brief, en het is
een kracht: je vraagt niet om een aanbesteding, je levert een ijkpunt.
